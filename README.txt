الحديقة الوردية — نادي المؤسس للابتكار والاستثمار

مهم: تم تجهيز الموقع للحفظ الجماعي عبر Supabase. حتى تظهر وردات جميع المشاركات من أجهزة مختلفة وتبقى بعد إغلاق الموقع، يلزم ربط قاعدة بيانات مجانية مرة واحدة (لا يمكن إنشاء قاعدة مشتركة بدون حساب/مشروع تملكينه).

خطوات الربط — مرة واحدة فقط:
1) افتحي https://supabase.com وأنشئي مشروعًا مجانيًا.
2) من Project Settings > API انسخي Project URL و anon/public key.
3) افتحي index.html وابحثي عن:
   const SUPABASE_URL = "ضعي_رابط_مشروعك_هنا";
   const SUPABASE_ANON_KEY = "ضعي_مفتاح_anon_هنا";
   واستبدلي النصين ببيانات مشروعك بين علامتي الاقتباس.
4) من SQL Editor في Supabase، الصقي وشغلي هذا الكود:

create table if not exists public.flowers (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) between 1 and 40),
  flower text not null check (flower in ('rose','tulip','daisy','peony','cherry','lily','lavender','carnation')),
  color text not null check (color ~ '^#[0-9A-Fa-f]{6}$'),
  created_at timestamptz not null default now()
);

alter table public.flowers enable row level security;
create policy "Anyone can view garden flowers" on public.flowers for select to anon using (true);
create policy "Anyone can plant a flower" on public.flowers for insert to anon with check (true);
alter publication supabase_realtime add table public.flowers;

إذا ظهر أن الجدول مضاف مسبقًا إلى supabase_realtime، احذفي آخر سطر من الكود وأعيدي تشغيل الباقي أو اتركي الجدول مضافًا بالفعل.
5) احفظي index.html ثم ارفعي index.html و logo.png إلى مستودع GitHub Pages.

بعد الربط: أي وردة تُزرع تُحفظ في قاعدة البيانات وتظهر تلقائيًا لدى جميع الزائرات، كما يُحدّث عداد الورود مباشرة. لا تضعي أبدًا service_role key في الموقع؛ استخدمي anon/public key فقط.

ملاحظة الخصوصية: الاسم الذي تكتبه المشاركة سيكون ظاهرًا في الحديقة المشتركة. أخبري المشاركات بذلك قبل الاستخدام.
